Privacy Policy

Last updated: 22 November 2026

"You're The President Uploader" is a private tool used only by the owner of the YouTube channel You're The President to upload and schedule that channel's own videos. It is not offered to the public.

What the tool accesses

With the owner's permission (Google OAuth), the tool uses the YouTube Data API to upload videos to the owner's channel, set their title, description, thumbnail and publishing time, and read the channel's basic information to confirm it is the right channel.

What data is stored

The only data stored is the authorization token, kept on the owner's own computer. No data about viewers or other YouTube users is collected, stored, sold or shared.

Google API Services

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements, and to the YouTube Terms of Service. Google's privacy policy: policies.google.com/privacy.

YouTube API Services

This tool uses YouTube API Services. By using it, the channel owner agrees to be bound by the YouTube Terms of Service.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions or through the Google security settings page. When access is revoked, the stored authorization token stops working and is deleted from the owner's computer. The tool keeps no other copy of any API data; nothing is stored for more than 30 days.
